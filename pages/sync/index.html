OFFICIAL RCLONE GUI

高级配置

使用 rclone 自带的官方界面，直接管理同一份连接配置。服务运行期间暂停同步，15 分钟后自动停止；结束后重新检测连接。

远程访问需要映射以上两个端口；公网请通过 HTTPS 反向代理访问，GUI 与 API 分别使用一个域名。服务使用随机密码认证。

AstrBot 插件页面限制打开新窗口。请复制地址到浏览器打开；地址包含本次会话凭据，请勿分享。结束配置后该地址失效。
