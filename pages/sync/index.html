使用引导

连接设置有未保存的修改。请先返回主页面保存，再安装或配置存储。

先安装 rclone

rclone 是实际传输文件的工具，需要安装在 AstrBot 所在的机器或 Docker 容器内。

自动安装

点击下方按钮，插件会从官方源下载、校验并安装 rclone，完成后自动保存程序路径。

已经安装？

在主页面填写「rclone 可执行文件」并保存连接设置，然后进入下一步。可填写 rclone 或程序绝对路径，要求版本 ≥ 1.74。

添加存储，三种方式任选一种

三种方式共用同一份连接配置。首次使用建议选择插件配置向导。

插件配置向导推荐

直接在插件页面填写连接名称、选择网盘类型，再按提示完成授权，最后点击「保存连接」。

终端配置

将下面的完整命令复制到 AstrBot 所在机器或容器的终端执行，按菜单添加存储。命令已指定插件使用的配置文件。

执行前请暂停连接并结束页面配置会话；完成后回到主页面点击「读取」。

官方 GUI

启动 rclone 官方网页界面，复制登录地址到浏览器打开，再在官方界面添加连接。完成后结束配置服务。

OneDrive 等账号可能需要在有浏览器的电脑执行向导给出的授权命令，再将结果粘贴回向导。

选择连接，设置云端根目录

  1. 在主页面点击「读取」，选择刚添加的「连接名称」，例如 backup。
  2. 填写「云端同步根目录」。普通网盘可填 AstrBotSync；S3、R2 等对象存储填 桶名/AstrBotSync。
  3. 点击「保存连接设置」，再点击「检测并连接」。概况显示「已连接」即完成。

所有任务共用这里选定的存储连接和根目录；每个任务另设自己的云端子目录。

创建任务，预览后执行

每个任务只按一个方向同步。「本机」指 AstrBot 所在机器或容器；「云端子目录」相对于刚才设置的云端根目录。

模式方向目标端多余文件
上传更新本机 → 云端保留
镜像到云端本机 → 云端删除
下载更新云端 → 本机保留
镜像到本地云端 → 本机删除
  1. 点击「新建任务」，填写名称、模式和两端路径。
  2. 先点「预览变更」查看新增、更新和删除，再「保存任务」。
  3. 点击「立即同步」执行，在「执行记录」查看进度与结果。间隔为 0 时仅手动执行，1440 为每 24 小时一次。

同名文件可能被覆盖，镜像模式还会删除目标端多余文件。运行中的数据库请先导出或创建快照。

授权失效时，重新登录网盘

已添加的网盘因授权失效或被撤销而无法连接时使用。连接正常时通常无需操作，普通令牌刷新由 rclone 处理。

在插件中重新授权

针对已保存的当前连接重新进入授权步骤。完成后点击「保存连接」，再「检测并连接」；取消或超时会保留原配置。
